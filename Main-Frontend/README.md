# Soul of Braj Federation (SOBF) – Frontend

The **Soul of Braj Federation (SOBF)** website is the official application for the organization. It is built with **React** and **Vite**, providing a fast, responsive, and user-friendly experience for visitors to learn about the organization's mission, initiatives, events, media, and ways to contribute.

---

## 🌐 About Soul of Braj Federation

**Soul of Braj Federation (SOBF)** is a Section-8 recognized non-profit organization dedicated to serving underprivileged communities in Vrindavan and the Braj region. Through various social welfare initiatives, SOBF works towards creating a healthier, cleaner, and more empowered society.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project

```bash
cd Soul-Of-Braj
cd Main-Frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
